VLACORA HUB 0.23.0
Standalone organization + programming + editorial + social workflow release.

Backend:
- Supabase Auth remains the login/identity layer.
- Supabase PostgreSQL is the current application database.
- Supabase Storage is used for profile/program/social and generic HUB attachments.
- Architecture remains prepared for a later external PostgreSQL application-data backend while keeping Supabase Auth.

0.23.0 highlights:
- Real superadmin station management via hub_stations; add/deactivate/delete now persists in PostgreSQL.
- Copy station configuration by selectable sections (programming, team, templates, social, settings, contacts) or all.
- Personal calendar is private to the owner, including from admins; station and VLACORA calendars remain separate.
- Programs are linked to real Supabase accounts through hub_program_team (primary presenter + extra team/co-presenters).
- Presenter dashboards and “Mijn programma” use account IDs rather than name matching.
- Presenter/profile photos and program cover images.
- Absence impact + replacement workflow with program overrides.
- Editorial Talk-first workflow and automatic version history.
- Weekly, annual and special hitlists, historical editions, Excel import and trend/weeks/peak calculations.
- Excel parser supports the supplied Super 50 layout with DW / Artiest / Titel.
- Music/format proposals with Spotify/YouTube links, target folder/program, explanation and review status.
- Generic private HUB attachments for incidents, messenger, tasks, admin requests, content inbox, editorial, social, communications and music proposals.
- Official communication moved to PostgreSQL + attachments.
- Social Studio reorganized toward a calmer TOPhub-inspired workflow.
- Muziekmappen PDF removed.
- No Playout One, Rotation One, SHOUTcast/listener statistics or playout monitoring in active application code.
