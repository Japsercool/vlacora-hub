# Productie checklist

- [ ] Docker Compose valideert zonder fouten.
- [ ] PostgreSQL is healthy.
- [ ] 5432 is niet gepubliceerd.
- [ ] Gateway is healthy/ready.
- [ ] HTTPS-certificaat geldig.
- [ ] Nieuwe site-URL staat in Supabase Auth redirects.
- [ ] `VERIFY_PULSE_DOCKER` zonder blokkerende fouten.
- [ ] Recente backup aanwezig.
- [ ] Eerste migratie volledig groen.
- [ ] Bestanden 100% gekopieerd.
- [ ] Finale sync volledig groen.
- [ ] Webapp data-layer audit uitgevoerd.
- [ ] Rollback naar Supabase getest/gedocumenteerd.
- [ ] Supabase brondata nog niet verwijderd.
